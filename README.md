# Portfolio

A static UGC creator portfolio site, hosted on GitHub Pages.

- `index.html` – page content
- `styles.css` – styling
- `script.js` – header, mobile menu, and scroll animations
- `assets/videos/` – drop your video files here, then swap each placeholder
  `<div class="video-card"></div>` for
  `<video class="video-card" src="assets/videos/clip.mp4" controls playsinline preload="metadata"></video>`
